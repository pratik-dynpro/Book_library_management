# D15a · User Stories (v1 — business language)

Stories use the canonical "As a / I want / So that" form. Each maps to one or more features in `D3-FEATURE-CATALOG.md`. Build-precise acceptance criteria with column-level references live in `D15b-USER-STORIES-v2.md`.

| ID | Story | Feature |
|----|-------|---------|
| US-01 | As a reader, I want to add a book to my library so I can remember what I own. | F-002, F-004 |
| US-02 | As a reader, I want to see all my books on one page so I can browse my collection. | F-003 |
| US-03 | As a reader, I want to edit a book's details so I can fix typos or change its status. | F-002, F-004 |
| US-04 | As a reader, I want to delete a book so I can remove ones I no longer own. | F-002, F-003 |
| US-05 | As a reader, I want to search by title or author so I can find a specific book quickly. | F-005 |
| US-06 | As a reader, I want to filter by author so I can see everything by one writer. | F-006 |
| US-07 | As a reader, I want to filter by genre so I can browse a category. | F-006 |
| US-08 | As a reader, I want to filter by reading status so I can pick my next book from the unread pile. | F-006 |
| US-09 | As a reader, I want to see how many books I own and how many I've read so I can track progress. | F-007 |
| US-10 | As a reader, I want a friendly home page so the app feels finished, not bare. | F-001 |
| US-11 | As a reader, I want the app to work on my phone so I can use it on the couch. | F-001…F-006 (NFR Q-003) |
| US-12 | As a reader, I want form errors shown next to the field so I know what to fix. | F-004 |

## Priority

All twelve are **MUST** for v1. Anything labeled "nice to have" in conversation goes to `D8-BACKLOG.md` Level-2/3 enhancements, not here.
